Countdown Dots

Countdown Dots Support

Countdown Dots helps you create visual countdowns for important dates.

Common actions

  • Create an event from the Countdown or Events tab.
  • Add an event name and date; location and notes are optional.
  • Tap an event to make it the active countdown.
  • Use Details to edit, set a default event, or delete the selected event.
  • Use Settings to choose a dot layout and customise colours.

Countdown Dots does not require an account and stores event data locally on the device.

Contact support

For help or to report a problem, open an issue on GitHub.
